# [프로젝트 소개] GridOS — 한·일·대만·중국·미국의 인프라를 한 지도에서

안녕하세요. 공개 데이터에 흩어져 있는 에너지·산업·디지털 기반시설을 한 화면에서
탐색할 수 있는 **GridOS**를 만들었습니다.

- 데모: [https://oswarld.github.io/gridos/](https://oswarld.github.io/gridos/)
- GitHub: [https://github.com/oswarld/gridos](https://github.com/oswarld/gridos)

![GridOS Public Infrastructure Atlas](https://oswarld.github.io/gridos/og.png)

## 왜 만들었나요?

발전소, 송전망, 에너지 파이프라인, 데이터센터, 네트워크 허브는 서로 영향을
주고받지만 공개 정보는 기관·사업자·국가별로 흩어져 있습니다. 같은 지역의
시설을 함께 보거나, 시설의 운영사와 원문 근거를 따라가려면 여러 자료를 직접
맞춰 봐야 했습니다.

GridOS는 이 자료를 하나의 “완성된 시설 대장”으로 단정하는 대신, **무엇이 어떤
원천에서 공개됐는지 확인할 수 있는 근거 지도**로 연결하는 데 초점을 맞췄습니다.

## 지금 할 수 있는 것

- 첫 방문 시 접속 지역에 맞는 언어와 국가 상세 지도로 자동 시작
- 대한민국·일본·대만·중국·미국의 기반시설 레이어 탐색
- 발전소, 송전망, 에너지 파이프라인, 데이터센터, 네트워크 허브 조합 표시
- 발전 용량·연료·계획 시설 여부·IX 연결·네트워크 수 필터
- 공개 자료에 명시된 운영사·소유주·시설 관계와 원문 확인
- 지역별 관측 전력수요와 재생에너지 발전량 비교
- 운영사에서 상장기업·거래소·티커로 이어지는 공개 식별 관계 확인
- 한국어·영어·일본어·중국어(간체) UI

자동 선택은 사용자가 직접 고른 언어와 국가를 우선합니다. 외부 IP 위치 조회
서비스나 새 위치 권한 요청 없이 브라우저 시간대·언어를 사용하고, 위치 권한이
이미 허용된 경우에만 기기 위치로 보정합니다.

현재 `v1.0.0` 빌드 스냅샷에는 5개국 상세 포인트 약 **5.5만 건**과 송전망·배관
등 선형 피처 약 **3.6만 건**이 포함돼 있습니다.

## 데이터를 다룰 때 정한 원칙

기반시설 데이터인 만큼 “공개되어 있다”는 이유만으로 모든 정보를 결합하거나
더 정밀하게 추론하는 것은 피했습니다.

1. 원천이 직접 공개한 위치와 공개 수준만 사용합니다.
2. 공개되지 않은 송전·배관·변전소 위치를 공간 추론으로 복원하지 않습니다.
3. 일반화된 위치를 임의의 정밀 좌표로 바꾸지 않습니다.
4. 단순 근접성과 원천이 확인한 물리적 연결을 구분합니다.
5. 가능한 모든 레코드에 원문 URL, 기준일, 수집시점과 출처를 연결합니다.

OpenStreetMap, U.S. EIA, HIFLD, PeeringDB와 각국 전력기관·사업자·공시·거래소의
공개 자료를 사용했습니다. 개별 데이터는 각 원천의 라이선스와 이용조건을
따릅니다.

## 기술 구성

- Next.js 15 / React 19 / TypeScript
- MapLibre GL
- Supabase
- Tailwind CSS
- GitHub Pages 정적 배포

로컬에서는 아래 명령으로 실행할 수 있습니다.

```bash
git clone https://github.com/oswarld/gridos.git
cd gridos
pnpm install
pnpm dev
```

저장소에 검증된 스냅샷이 포함돼 있어 첫 실행에는 별도 API 키가 필요 없습니다.

## 아직 부족한 점

- 국가와 원천마다 기준일·공개 범위·위치 정밀도가 다릅니다.
- 지도는 각국의 완전한 시설 대장이 아닙니다.
- 수요와 공급 지표의 모집단이 다른 경우가 있어 화면에 방법론을 함께 표시합니다.
- 기업·티커 연결은 공개 식별 관계일 뿐 투자 추천이 아닙니다.
- 별도 소프트웨어 라이선스가 아직 없어, 현재 소스 공개가 코드 재사용 허가를
  뜻하지는 않습니다.

제14회 산업통상부 공공데이터 활용 아이디어 공모전에도 출품했습니다.

지도 사용성, 빠진 공개 원천, 잘못 연결된 시설이나 운영사, 데이터 공개 원칙에
대한 의견을 받고 싶습니다. 오류나 정정은
[GitHub Issues](https://github.com/oswarld/gridos/issues)에 남겨주세요.
